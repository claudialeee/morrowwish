## Continuous fixes, scoped regression, final acceptance

Routine pushes select affected chapters only when every changed file belongs to a deliberately narrow, audited presentation-file allowlist (currently harbor and forge). Shared code, unclassified files, missing diff base, and mixed unknown changes fail open to all eight chapters. Selection uses the entire push diff; the selected IDs and changed paths are logged. Manual dispatch accepts chapters, tail, or comma-separated chapter IDs for debugging. A scoped pass is never final release approval. Explicit [qa-full] or [fresh-campaign] runs all chapters in a separate concurrency lane, with fresh-slot acceptance still required before release. Keep fixing confirmed defects while prior tests run; do not attach [replace-obsolete-qa] to ordinary patches. Reuse earlier evidence only with verified unchanged dependencies and exact SHA, never across unknown shared runtime changes. After the last functional fix, run all eight chapters and fresh-slot acceptance once against one candidate SHA; if another fix is necessary, resume scoped repair then reconfirm the final candidate. The selector includes fail-safe self-tests run before every browser matrix.

## Integrated adoption

The [qa-toolchain] marker is scoped only when the entire push diff consists of the seven QA integration files; a missing diff or any other changed file falls back to the complete chapter matrix. This lane is separate from existing chapter and final runs. Ordinary preview pushes no longer trigger on the preview workflow file alone (manual dispatch remains available). Fresh concurrency is on eligible matrix jobs, so skipped ordinary pushes do not replace a pending final acceptance. Stable-system runs are not automatically cancelled for ordinary patches. Current running tests retain their original runtime evidence. This policy does not authorize release on a scoped smoke. Do not use [replace-obsolete-qa] for routine fixes; fix continuously, use automatic scope selection or a manual affected chapter, and run final full plus fresh on the final candidate.
