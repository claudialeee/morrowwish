# 星铃回响 Canon 2.1 — 美术重置决策
**状态：基于资产清单、剧情功能与现有核心重制记录的审查；非逐像素视觉验收。** 本文对应 [新版剧本](02-MAIN-STORY-SCRIPT.md)、[原美术画廊](ART-REVIEW.md)、[核心重制清单](CORE-ART-REMASTER.md)。没有制作或替换新图，没有为候选镜头签字。质量优先，不因已经投入的工作保留不合适的美术。

## 总方向
统一温暖、细腻的绘本水彩奇幻风格。地图必须可读、可探索，前中后景分层，角色比例与交互一致。活动光影、根桥、门、星路、云层必须可动态呈现；不能把它们全部烘焙进静态底图。文字与操作指示由双语 UI 实现。移动端、横竖屏均留足操作空间。

## P0：按实际玩法生产
这是六组地区视觉重构及两组优先怪物设计，不是硬性限定图片数量。优先制作可复用的透明分层素材与底图，动画和反馈由游戏引擎完成。
1. **风铃镇：会跑的铃声。** 山谷小镇、水彩风铃集市、石板小巷、低围墙、旧铃房、可辨的双路线；不得出现码头、船或灯塔。金蓝猫耳光团透明素材，成长后的铃光兽采用同样轮廓母题，真身与假光圈有区别。
2. **眠根林：月叶迷宫。** 树冠与地下支路、古树、会打喷嚏的花，伸展与收起的根桥、真/假花状态分层。保证探索空间不是装饰。
3. **千灯城：灯火节、影子戏。** 彩色猫耳灯、节庆广场、剪影舞台、被影子遮住的真实石桥、灯光范围、透明剪影兽真/假状态；灯光与影子必须响应玩家输入。禁止实体影桥或满屏彩色粒子充当奇幻感。
4. **云脊群岛：云瀑、月门。** 可飞路线、可读的上升气流与回卷风带、浮岛门、前景云层、茶席；实际操控优先于飞行插画。
5. **月镜书库：能走进去的镜子。** 镜框、可识别的旧地区变体、壁画、镜面守卫；六铃模型由 UI/动态层表达。严格限制历史图出现时机。
6. **星坠原：脚下星光。** 动态亮起的踏石、清晰可辨的落点、遗迹与中央铃；F-02 历史画保持人物与灾难一致。
7. **终章：六地合力。** 复用新地区动态层和伙伴技能，表现风铃镇真铃、森林根桥、千灯城彩灯、天空风圈、镜面、星桥的实际战斗贡献。若旧场地不适用，重画而不是减少高潮。仅两种玩家机制，六地支援由NPC在场内外实际完成，不堆六套小游戏。

## P1：情感、音画
- 优先补充 S-04 云海茶席关键图（如实际角色场景表现已充分，可不加静态图）：金渐层和银渐层平等并坐，两杯茶，暮铃若有所思。不画修铃坠，不提前揭露过去。
- H-04 双猫胜利、灯火节重亮、终章合唱须先有实际游戏表现。只有实机情感回报不足时再增加演出插画。
- 六地区真实回应需要各自不同的音色，同时提供视觉替代；不要求听力或辨音能力。BGM 统一温暖奇幻冒险，危机时增强节奏但不突然惊吓。

## 验收
先确定新玩法布局与角色行走范围，再锁图；逐地区以桌面和移动端实机检查可玩空间、视觉层次、交互反馈、角色一致性、语言无烘焙文字、动画与声音。逐张核对来源、用途、实际接入、候选批准状态。旧画廊中的文件数量和解码成功均不能替代视觉验收。禁止为节省原有工作而迁就无聊的故事。
