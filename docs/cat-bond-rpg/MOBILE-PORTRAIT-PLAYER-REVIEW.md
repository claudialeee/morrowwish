# 星铃回响 · 竖屏首局试玩评估

在公开竖屏试玩版以 390×844 创建英文新存档。亲自走过首页、存档选择、序章、花园对话、追图纸、查看古铃、回报暮铃，进入风铃镇并选择和栖蓝交谈。以下实测范围止于风铃镇任务开场。后续章节只作剧本评估。

| 视角 | 观察 | 交接建议 |
| --- | --- | --- |
| 陌生玩家 · 第一印象 | 两只非剧透封面猫亲和力强。方画浮在渐变背景上，上下割裂。选择新冒险之后还需要从三个空槽中再选一次。 | 竖屏封面使用整屏插画，上方留标题，下方放开玩操作。首次全部空槽时优先把一个开始动作做突出。 |
| 陌生玩家 · 剧情牵引 | “忘了自己的名字”是清楚的个人目标。“铃绳没动，铃却回了我哼的两声”是第一个独属于这游戏的悬念。当前它主要作为短提示出现，玩家可以先被更显眼的“下一场景”带走。 | 让铃的两声回应成为入镇前最显眼的反馈。播放两音并给铃一次清楚的视觉响应。在已有跳过路径之外，正常入口先强调追查线索。 |
| 陌生玩家 · 操作反馈 | 取图纸、摸铃、回访暮铃的目标能理解，但动态标记把“Windblown”拆成两行。花园静态大卡挡住玩家猫的脚和身体。 | 只展开当前核心线索的标签，周围可选物先用图标。把任务卡底置收拢，角色和路径保持可见。 |
| 制作人 · 风铃镇布局 | 地图约占屏高四分之一。主线卡、任务动作和地图区域重复强调同一入口，缩放按钮又占两行。 | 让地图铺满舞台。上方只保留单行目标，下方给一个可收起的任务抽屉，缩放与跟随归到地图工具。让追铃和低墙捷径在画面上先读得出来。 |
| 制作人 · 持续游玩动力 | 剧本设计有追铃、根桥、影戏、滑翔、辨认伙伴和星光路线等不同动作。这些章节实际节奏仍需独立体验。 | 逐章验收三个时刻：玩家能指出一个想验证的线索、能说出玩法选择导致什么变化、能看到这一章给后续人物关系或悬念带来什么回报。优先检验铃声回响和暮铃关系，不用小游戏数量衡量留存。 |

- 保留已在 390×844 实机铺满的庭院底图。优先处理任务卡遮挡、提示断词和交互层级。
- 首屏插画路径为 `public/cat-bond/assets/mobile-portrait/title-bell-sanctuary.webp`。标题安全区约 x=.16–.84、y=.08–.19，猫咪主体约 x=.13–.87、y=.41–.70，底部按钮建议在 y=.86–.96。坐标以原画左上为原点。
