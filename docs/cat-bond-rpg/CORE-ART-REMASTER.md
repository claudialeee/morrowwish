# 核心美术重制

角色原画采用带透明通道的 WebP。每只收藏猫一张全身图，供收藏、地图、战斗与庭院共用。两位主角另各有一张对话表情。

金渐层的迎面迈步、右扬尾、短马甲和圆背包，与暮铃的沉静站姿、左侧羽尾、贴身紫外套和侧挎包相互区分。
