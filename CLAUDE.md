# Morrow Wish — AI development instructions

You are editing the EXISTING Morrow Wish browser-game studio, not building a standalone website.

## Project

- GitHub: https://github.com/claudialeee/morrowwish (private)
- Public URL: https://morrowwish.vercel.app/
- Dashboard: https://morrowwish.vercel.app/studio-insights/
- Actual production host: Cloudflare Pages project `morrowwish`
- Cloudflare D1 analytics: `morrowwish-analytics`
- Vercel only forwards to Pages; DO NOT redeploy Vercel.

## Rules

1. Read README.md and inspect the latest `main` branch before editing.
2. Preserve Tiny Town v3, Elsewhere, all games, assets and D1 data. Do not rewrite unrelated files.
3. Create new games under `public/<slug>/`.
4. Add a corresponding homepage card to `public/index.html`.
5. Integrate events with existing `public/telemetry.js` and `window.arcadeMetric` conventions. Follow DNT/GPC.
6. Add correct game names, tracking and order to `public/studio-insights/index.html`. Homepage first; game rows match homepage ordering.
7. Keep all games bilingual and use the branding **Morrow Wish**; always spell **Elsewhere** with a capital E.
8. Never commit secrets, Cloudflare tokens, Analytics passwords, or OAuth credentials.
9. `npm run check` before PR; manually verify gameplay on desktop/mobile and test the Analytics endpoints.
10. Collaborators: push a feature branch and create a PR. DO NOT merge or deploy unless explicitly authorized by the owner.
11. Owner deployment: `npm run deploy` -> Cloudflare Pages project `morrowwish` only. NEVER deploy Vercel.
12. Do not create extra Workers or Pages projects, overwrite/delete D1 records, buy domains, or change billing.
13. Edit `public/` and `src/` only; `cloudflare-pages/public/` is generated by build scripts.

Report new game link, changes, tests, analytics verification and the PR URL.
